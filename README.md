# Falkenrath — Personal Portfolio

A personal portfolio showcasing my journey, projects, experiences, and interests in software development, creative design, and digital technology.

Designed to represent my personal identity, creative perspective, and continuous exploration of the digital world.

## Overview

This portfolio serves as my personal space on the internet — a place to present who I am, what I do, what I have created, and what I aspire to achieve.

It brings together my technical interests, creative works, professional experiences, and personal journey in one place.

## Features

- **Personal Introduction** — A brief introduction and overview of my identity.
- **About Me** — Background, interests, and personal journey.
- **Skills & Expertise** — An overview of my capabilities and areas of interest.
- **Selected Projects** — A showcase of selected works and experiments.
- **Experience** — Professional, organisational, and volunteering experiences.
- **Achievements** — Selected accomplishments and recognitions.
- **Activities** — Creative interests and personal activities.
- **Contact** — Ways to connect and collaborate.

## Design Philosophy

The website follows a minimalist and modern visual direction, focusing on:

- Clean and sophisticated layouts.
- Dark and light appearance modes.
- Clear typography and visual hierarchy.
- Subtle animations and interactions.
- Responsive design across different devices.
- A balance between personal expression and professional presentation.

## Getting Started

To run this project locally:

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd YOUR_PROJECT_FOLDER
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
